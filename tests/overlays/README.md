保存的发行版快照缺少命令面板、模型选择和移动抽屉等按需加载的模块，当前后台也未运行。因此这部分使用真实源码样式和 DOM 结构验证几何布局，不能代表实际组件交互已经验证。图片预览来自发行版真实组件，通过实际读取图片工具打开。

要复现修改前的图片问题：PowerShell 中设置 `$env:OCW_OVERLAY_MODE = 'baseline'`，再运行 `bun run run.mjs --grep reproduces`。正常测试不设置这个变量。
